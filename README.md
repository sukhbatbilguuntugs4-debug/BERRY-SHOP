# BERRY — Захиалгын систем (Backend)

Энэ хавтас нь таны дэлгүүрийн сайтыг **жинхэнэ, ажилладаг захиалгын системтэй** болгож өгнө:
- Хэрэглэгч "Захиалга өгөх" дархад захиалга серверт хадгалагдана (`data/orders.json`)
- Та `/admin.html` хуудаснаас бүх захиалгыг харна

## Юу орсон бэ?
```
berry-backend/
  server.js       ← backend сервер (Node.js + Express)
  package.json    ← хэрэгтэй сангуудын жагсаалт
  public/
    index.html    ← таны дэлгүүрийн сайт (backend-тэй холбогдсон хувилбар)
    admin.html    ← захиалга харах админ хуудас
  data/
    orders.json   ← захиалгууд энд автоматаар хадгалагдана
```

## Хэрхэн байршуулах вэ (Render.com — үнэгүй)

1. **Render.com** дээр бүртгүүлнэ (эсвэл GitHub-аараа нэвтэрнэ) → https://render.com
2. Энэ `berry-backend` хавтсыг GitHub repo болгож upload хийнэ (GitHub.com дээр шинэ repo үүсгээд файлуудыг чирж оруулаад л болно)
3. Render дээр **"New +" → "Web Service"** дарж, дээрх GitHub repo-г сонгоно
4. Тохиргоо:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment Variable нэмэх:** `ADMIN_KEY` = өөрийн нууц үг (жишээ нь `berry-admin-2026-xyz`)
5. **"Create Web Service"** дарна → 2-3 минутын дараа танд `https://berry-xxxx.onrender.com` шиг холбоос өгнө
6. Энэ холбоос бол таны **шинэ дэлгүүрийн сайт** — үүнийг хэрэглэгчдэд түгээнэ үү

## Захиалгаа хэрхэн харах вэ?

`https://berry-xxxx.onrender.com/admin.html` руу орж, `ADMIN_KEY`-гээ (дээрх алхам 4-т орсон утга) оруулаад "Ачаалах" дарна. Бүх захиалга хүснэгтээр харагдана.

## Анхаарах зүйлс

- **Render үнэгүй tier**-д 15 минут хэрэглэгдээгүй бол сервер "унтдаг" — дараагийн хүн орох үед 20-30 секунд ачаалахад цаг зарцуулна. Байнга ашиглах бол цалинтай (paid) tier руу шилжинэ.
- `data/orders.json` файл нь серверийн диск дээр хадгалагддаг тул Render-ийг дахин deploy хийх бүрт **устаж магадгүй** (free tier-ийн disk persistence хязгаарлагдмал). Урт хугацаанд найдвартай байлгахын тулд жинхэнэ өгөгдлийн сан (жишээ нь Postgres, MongoDB Atlas — хоёул үнэгүй tier-тэй) руу шилжих нь дээр. Хэрэгтэй бол би энэ хувилбарыг бас хийж өгье.
- Одоогийн байдлаар админ хуудас зөвхөн нэг нууц түлхүүрээр хамгаалагдсан — жинхэнэ бизнест ашиглахаас өмнө илүү найдвартай нэвтрэлт (жишээ нь username+password) нэмэх зөвлөмжтэй.

## Локал дээр туршиж үзэх (заавал биш)

Хэрэв компьютертоо Node.js суулгасан бол:
```bash
cd berry-backend
npm install
npm start
```
Дараа нь `http://localhost:3000` руу орж шалгаж болно.
